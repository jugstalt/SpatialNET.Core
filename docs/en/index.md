# SpatialNET

SpatialNET is a library for planar spatial computations that works exclusively through interfaces, so that existing GIS software can use it through its own geometry classes.

- **API reference**: generated from the XML comments, see [API reference](api/index.md).
- **Design decisions**: the architecture decision records are listed under [Decisions](decisions/toc.yml).
- **Research notes**: background on the algorithm choices under [Research](https://github.com/jugstalt/SpatialNET.Core/tree/main/research).
